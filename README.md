# Navi Labs — site public

Site de l'éditeur **Navi Labs** (applications Android), publié avec GitHub Pages
à l'adresse https://navilabs-dev.github.io. Pages non référencées par les moteurs
de recherche (`noindex`).

- `index.html` — page du studio (français, anglais, espagnol)
- `navistream/index.html` — présentation de NaviStream (lecteur IPTV)
- `navistream/privacy.html` — politique de confidentialité de NaviStream
- `app-ads.txt` — vendeurs publicitaires autorisés (AdMob), valable pour toutes les applications
- `style.css` — mise en forme

Le code des applications n'est pas dans ce dépôt.
